
# Day 05 - Learning Log
## HTML Forms & Inputs

### 1. What I Built
I created a Student Registration Demo Form using HTML.
The form includes name, email, age, course, study mode,
learning goals and practice-data confirmation fields.

### 2. Validation Checks I Tested
- Tested the form with empty required fields.
- Entered an invalid email address and checked browser validation.
- Tested age input and successfully submitted the form.

### 3. One Bug I Fixed
Initially, the age field had minimum and maximum limits.
I removed the min and max attributes to allow different age values.

### 4. Why Client-Side Validation Is Not Enough
Client-side validation can be bypassed by users.
A real application must also validate data on the server
to protect information and maintain security.

### 5. One Future Improvement
I would connect the form to a backend and database
so that student registration details can be stored securely.
