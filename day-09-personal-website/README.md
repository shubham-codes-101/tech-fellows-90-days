# Day 09: CSS Selectors, Spacing and Box Model

## Project description
An updated two-page personal website for Shubham Singh, made for the Tech Fellows Day 09 practical task.

## Project files
- `index.html`: Home page
- `about.html`: About page
- `style.css`: Shared stylesheet
- `images/profile.svg`: Temporary profile image placeholder
- `images/logo.svg`: Site logo

## How to run
1. Extract this project folder.
2. Open `day-09-personal-website` in Visual Studio Code.
3. Open `index.html` with Live Server or a browser.
4. Use Home and About Me links to test navigation.

## CSS concepts demonstrated
- Element selector: `p`
- Class selector: `.content-section`
- ID selector: `#page-title` on both pages
- Bonus reusable class: `.card`
- Margin, padding, borders and rounded corners
- `box-sizing: border-box` using universal selectors
- Responsive media query

## Profile photo
`images/profile.svg` is a placeholder. To use your own photo, copy it into the `images` folder as `profile.jpg` and change the image source in `index.html` from `images/profile.svg` to `images/profile.jpg`.

## Margin and padding
- Margin is space outside an element, separating it from nearby elements.
- Padding is space inside an element, between its content and its border.
