SHUBHAM SINGH - STUDENT DEVELOPER PORTFOLIO

Files:
- index.html: one-page portfolio
- style.css: external stylesheet and responsive design
- script.js: dark mode, mobile menu and email form behavior
- images/profile.jpg: profile photo supplied for this project

To preview:
1. Open this folder in VS Code.
2. Open index.html with Live Server.
3. Test navigation, dark mode, mobile menu and contact form.

Before publishing:
- Replace shubham@example.com in index.html and script.js with your real email address.
- The contact form opens the visitor's default email app. It does not store or send messages through a server.
- Review the skills progress bars and project descriptions to ensure they accurately represent your experience.

GitHub Pages:
Upload these files into a folder such as month-1 in your tech-fellows-90-days repository. Enable GitHub Pages for the main branch if it is not already enabled. The URL will follow:
