# Day 02 Reflection

## 1. Tag, Element and Attribute
A tag is the HTML markup used to define an element.
An element includes the opening tag, content and closing tag.
An attribute provides extra information about an HTML element.

## 2. Ordered List vs Unordered List
An ordered list uses numbers.
An unordered list uses bullet points.

## 3. Importance of Alt Text
Alt text describes an image. It helps screen readers understand images and displays useful text if an image cannot load.

## 4. Broken Internal Link Test
When I changed the About Me section ID, the navigation link stopped working.
The problem was caused by a mismatch between the href value and the section ID.
I fixed it by restoring the correct ID.

## 5. Issue, Cause and Fix
Issue: Profile image was not displaying.
Cause: The image was not placed in the correct images folder.
Fix: I created the correct images folder and moved profile.jpg into it. The image displayed successfully after refreshing the browser.

## 6. What I Learned
I learned how to structure an HTML page using semantic elements, create navigation links, add images and use lists.
